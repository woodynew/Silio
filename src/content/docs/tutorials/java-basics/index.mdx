在这个系列中，我们将摒弃枯燥的语法说教，从真实需求出发，带你一步步构建一个属于自己的记账本控制台应用。

## 你将学到

- 如何安装和配置 Java 开发环境
- 变量、数据类型、运算符等基础语法
- 控制流（`if/else`、`for`、`while`）
- 函数与方法的封装
- 面向对象编程（OOP）初探
- 集合框架（`List`、`Map` 等）的使用
