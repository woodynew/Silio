## Context
市面上的 Java 教程过于理论，初学者往往缺乏把技术进行串联解决实际问题的能力。需要建立一个实战导向的教程平台。当前的 MVP 被定位为纯静态架构前端展示站点，完全抛却后端依赖，追求快速上线和极佳的开发者阅读体验（暗黑模式、高级架构图渲染）。

## Goals / Non-Goals
**Goals:**
*   提供具有极致排版和阅读体验的外壳设计（暗黑模式、Java 代码高级高亮、支持 Mermaid 架构图直接渲染）。
*   实现脱离后端的阅读进度本地保存和回显机制。
*   提供极速的纯前端全局 Markdown 内容检索。

**Non-Goals:**
*   由于是纯静态，MVP 不涉及服务端的部署与数据库/缓存架构设计。
*   明确排除浏览器端的在线 Java 代码沙箱运行环境整合。

## Decisions
*   **选用 Astro + Starlight 作为静态构建框架**：Starlight 是 Astro 官方维护的专注文档建设的模板，开箱即用，支持 MDX 和灵活的组件定制，构建速度极快。对于纯前端的图说教程非常理想。
*   **进度保存在 LocalStorage**：编写一个简单的 React/Svelte Islands 组件，在 MDX 页面内引入，负责读取与写入当前文章的阅读状态到 LocalStorage，在侧边栏做状态回显映射。
*   **全局搜索选用 Pagefind**：构建时只需在输出的静态 HTML 目录执行一次 Pagefind CLI 生成静态索引结构，彻底不占用运行时的服务器资源。

## Risks / Trade-offs
*   [数据丢失与多端不通风险] LocalStorage 容易被清理或移动端/PC端不同步。 → 这是一个可接受妥协点，因为此 MVP 是为了快速上线内容试水验证 PMF，后续可以通过扩充 SpringBoot 后端记录状态解决。
*   [无在线打分与社区讨论] 纯静态无法做答疑交流。 → 采用引流到 GitHub Discussions 或者 Issue 的变通方式。
