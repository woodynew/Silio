# Silio (希理)

**Logic with Resilience.** | **有韧性的逻辑**

Silio 是一个聚焦实战与底层逻辑的新一代 Java 学习平台。Java 学习者目前最缺的不是语法手册，而是**“如何把技术串联起来解决实际问题”**。Silio 致力于提供从零基础到架构师的高质量实战路径、交互式编码体验以及底层原理的深度图解。

---

## 🎯 核心目标与内容架构

Silio 不提供枯燥的八股文，而是提供一份直通生产环境的“路线图”。

### 分级实战路径

- **入门级**：手写简易 HTTP 服务器（深入理解 Socket 与网络协议）。
- **进阶级**：基于 Spring Boot + MyBatis Plus 开发完整“图书管理系统”。
- **高手级**：基于微服务架构（Spring Cloud Alibaba）构建“秒杀系统”与“分布式任务调度”。
- **面试级**：深入 JVM 调优案例、MySQL 索引优化实战。

### 生产级“避坑指南”与图解剖析

- **事故复盘专栏**：深度解析真实的内存溢出、死锁、慢 SQL 案例，不光教你“怎么写”，更教你“为什么绝对不能那样写”。
- **底层逻辑图解**：利用 Mermaid.js 等工具，将多线程状态、JVM 内存模型、Spring Bean 生命周期等抽象概念直观可视化。

---

## ✨ 现代化交互体验

摒弃传统的静态电子书模式，打造沉浸式学习体验：

- **交互式代码演练**：集成 Shiki/Prism.js 实现极美代码高亮；基于 WebContainer/CodeSandbox，允许用户在浏览器中直接运行和修改 Java 代码片段。
- **全文本极速检索**：集成 Pagefind，提供极轻量、瞬间响应的纯前端全文搜索。
- **学习进度追踪**：支持跨设备的进度记录，明确目标、减少学习焦虑。
- **极客阅读体验**：标配顺滑暗黑模式，双栏护眼导航（左侧章节树 + 右侧大纲），完美适配移动端。
- **离线学习支持**：一键将实战系列导出为 PDF/Epub，随时随地查阅。

---

## 🛠 技术栈与架构演进

Silio 采用现代化前沿架构，兼顾极致的文档体验与硬核的后端支撑：

- **项目管理**：全面规范使用 `pnpm` 作为包管理器。
- **前端方案 (Astro + Starlight)**：天生为高性能文档而生。原生支持 MDX，允许在 Markdown 中无缝嵌入 React/Vue 交互式组件（如“JVM 堆栈动态演示组件”）。
- **后端演进 (Java Spring Boot)**：
  - **核心服务**：Spring Boot 3.2+（深度利用 Virtual Threads 虚拟线程）。
  - **安全认证**：初期采用 JWT，平滑演进至 Spring Security + OAuth2 体系。
  - **持久层**：灵活搭配 MyBatis Flex / Spring Data JPA。
- **基础设施部署**：
  - 前端：Vercel / GitHub Pages 自动化流水线。
  - 后端：Docker 容器化部署。

## 🚀 发展路线图 (Roadmap)

我们正在敏捷推进 Silio 的产品落地：

- **第 1 阶段 (MVP 外壳层)**：基于 Astro Starlight 初始化项目骨架，完成 UI 定制与暗黑模式适配。
- **第 2 阶段 (内容破冰期)**：上线第一个核心系列《Java 零基础实战：开发一个记账本》，打通 MDX 交互式代码渲染。
- **第 3 阶段 (全渠道分发)**：接入 CI/CD 流水线，实现 Vercel 内容全自动发布。
- **第 4 阶段 (平台化演进)**：上线 Spring Boot 后端服务，开放用户评论、跨端进度同步及更多动态特性。
